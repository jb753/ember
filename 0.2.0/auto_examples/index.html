Examples¶

A gallery of worked examples demonstrating the ember API.

plot_*.py examples run on every make docs build.

run_*.py examples are expensive (multigrid solves taking many seconds to minutes) and are only executed by make docs-full; a normal build shows their source unexecuted, reusing whatever output was last generated.
