ember¶

An ‘Enhanced Multi-Block solvER’ for turbomachinery computational fluid dynamics, written by James Brind at the Whittle Laboratory, University of Cambridge. Solves the compressible Reynolds-averaged Navier-Stokes equations on multi-block structured meshes, using an evolution of the fast and robust Denton algorithms. Pre- and post-processing is handled through a numpy-like Python interface, while the heavy computations run through compiled Fortran for speed.
